=====================================================================
 DTMod 1.0 — кооператив для Devices Tycoon через Steam
 DTMod 1.0 — Devices Tycoon co-op via Steam
=====================================================================

[RU]
Что это
  Мод добавляет в главное меню кнопку «Кооператив». Хост создаёт игру, друзья входят
  в его лобби, хост нажимает «Начать игру» — и у всех в лобби стартует новая игра
  (каждый играет за свою компанию). В уже идущую игру можно войти позже.
  Компании игроков видны в списке компаний игры (Статистика → Рынок) и в рейтинге мода.
  Интерфейс на русском и английском (переключатель RU/EN).

Установка (у КАЖДОГО игрока)
  1. Закройте игру.
  2. Запустите DTMod-Setup.exe и выберите [1] Установить.
     Установщик сам найдёт игру через Steam. Если не найдёт — вставьте путь к папке игры.
  3. Запустите игру из Steam. В главном меню появится кнопка «Кооператив» (или F8).
  Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» ->
  «Выполнить в любом случае» (программа не подписана).

Как играть вместе
  Хост: Кооператив -> «Создать игру» -> название лобби, число игроков, доступ, название
  вашей компании, страна, слот сохранения -> «Создать лобби». Позовите друзей кнопкой
  «Пригласить через Steam…» (или они найдут открытое лобби в «Присоединиться»).
  Когда все в лобби — нажмите «Начать игру». У остальных появится отсчёт 5 секунд
  и их игра стартует сама (у кого уже идёт игра — спросит подтверждение).
  Позже зашедший игрок видит «Игра уже идёт» и нажимает «Создать компанию и войти»:
  его новая компания сразу стартует с текущей даты хоста (без перемотки, без «пропущенных» событий).
  Если хост играет на своём сохранении: в игре Кооператив -> вкладка «Лобби» ->
  «Открыть игру для других».
  У всех должна быть одна и та же версия мода.
  Слот сохранения: кооп-игра автосохраняется в выбранный слот (по умолчанию 3), одиночные
  сохранения в слотах 1–2 не трогаются.

Что синхронизируется
  Общий календарь (время ведёт хост: скорость, пауза), общий рынок ИИ-конкурентов и общие цены акций (бета),
  рейтинг игроков и их компании в списке компаний, переводы денег/очков исследований,
  текстовый и голосовой чат (V — говорить, клавишу можно сменить).
  Каждый продаёт со своей компании; сами устройства и мир целиком между ПК не копируются.
  Акции: цены у всех одинаковые (ведёт хост); портфель и доступные к покупке пакеты у каждого свои,
  купленная вами (поглощённая) компания живёт по вашей стратегии.

Удаление
  Запустите DTMod-Setup.exe -> [2] Удалить. Оригинальные файлы игры восстанавливаются точно.
  После обновления игры в Steam запустите установщик ещё раз.

[EN]
What it is
  Adds a "Co-op" button to the main menu. The host creates a game, friends join the lobby,
  the host presses "Start game" and a new game starts for everyone in the lobby (each player
  runs their own company). You can also join a game that is already running.
  Players' companies appear in the game's company list (Statistics -> Market) and in the mod's ranking.
  UI in English and Russian (RU/EN switch).

Install (EVERY player)
  1. Close the game.
  2. Run DTMod-Setup.exe and choose [1] Install. It finds the game through Steam
     (or paste the game folder path).
  3. Start the game from Steam. A "Co-op" button appears in the main menu (or press F8).
  Windows SmartScreen may warn about an unknown publisher: "More info" -> "Run anyway"
  (the program is not code-signed).

Playing together
  Host: Co-op -> "Create game" -> lobby name, players, visibility, your company name,
  country, save slot -> "Create lobby". Invite friends with "Invite via Steam…"
  (or they find a public lobby under "Join game"). When everybody is in, press "Start game":
  the others get a 5 second countdown and their game starts automatically (players who are
  already in a game are asked to confirm).
  A player who joins later sees "A game is running" and presses "Create company and join":
  the new company starts right at the host's current date (no fast-forward, no catching up on missed events).
  If the host plays an existing save: in game Co-op -> Lobby tab -> "Open game for others".
  Everyone needs the same mod version.
  Save slot: the co-op game autosaves to the chosen slot (default 3); your single-player
  saves in slots 1-2 are left alone.

What is synchronised
  Shared calendar (the host sets speed and pause), shared AI market and shared stock prices (beta), player ranking and
  players' companies in the game's company list, money / research-coin transfers, text and
  voice chat (hold V to talk; the key can be changed).
  Everyone sells with their own company; the devices themselves and the whole world are not copied between PCs.
  Stocks: prices are the same for everybody (the host drives them); your portfolio and the shares on offer are yours,
  a company you take over follows your own strategy.

Uninstall
  Run DTMod-Setup.exe -> [2] Uninstall. Original game files are restored exactly.
  After a game update in Steam, run the installer again.
